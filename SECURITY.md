# Security Policy

Please report security issues using GitHub private vulnerability reporting if it is enabled for this repository. If private vulnerability reporting is not available, contact the maintainer privately before disclosing the issue publicly.

Do not include tenant secrets, client secrets, tokens, certificates, exported assessment data, or sensitive tenant metadata in public issues, discussions, pull requests, screenshots, or logs.

Assessment outputs can include sensitive Microsoft Entra tenant metadata. Protect exported JSON, CSV, Markdown, and HTML reports according to your organization's data handling requirements.
